# Knowledge Gaps

Last Updated: 2026-06-21

---

# Definition

A Knowledge Gap is not:

* A wrong question
* A low score

A Knowledge Gap is:

* A repeated weakness
* A missing prerequisite
* A root cause of mistakes

Only recurring issues should appear here.
